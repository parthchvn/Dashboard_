Your data, locally

The app reads a local DuckDB snapshot. It does not download the full dataset or trade on your behalf.

1. Ingest the original files

python -m xvi ingest \
  --trades /path/to/trades.parquet \
  --markets /path/to/markets.parquet \
  --source-revision YOUR_HF_COMMIT_SHA

2. Start the dashboard

python -m xvi serve

Use trades.parquet, not quant.parquet or users.parquet. Stop the server before replacing the database. Dataset and cache files stay outside Git.

Optional review overlay

pip install -e '.[review]'
python -m xvi review MARKET_ID \
  --news-attr /path/to/news_attr --level 30s

The adapter runs the existing detector on full observed history. It does not select research samples. The demo uses a separate synthetic archive under data/demo/.
